# ⚽ Fora de Jogo — Combate ao Racismo

## 📌 Sobre o projeto

O **Fora de Jogo** é um site desenvolvido com o objetivo de conscientizar as pessoas sobre o racismo, promover o respeito e incentivar a igualdade dentro e fora do esporte.

A proposta é utilizar o futebol como ponto de partida para abordar um problema que ainda está presente na sociedade, mostrando que o racismo não deve ter espaço em nenhum ambiente.

## 🎯 Objetivo

Criar uma plataforma informativa e educativa que contribua para a conscientização sobre o racismo, destacando a importância do respeito, da diversidade e da inclusão.

## 💻 Tecnologias utilizadas

- HTML5 — Estruturação das páginas.
- CSS3 — Estilização e identidade visual.
- JavaScript — Recursos de interatividade.

## 🎨 Identidade visual

O projeto utiliza um estilo visual **Dark**, com uma interface moderna, simples e intuitiva, buscando proporcionar uma experiência agradável para os visitantes.

## 🚀 Funcionalidades

- Apresentação da campanha contra o racismo.
- Conteúdo informativo e educativo.
- Interface moderna e responsiva.
- Navegação simples e intuitiva.
- Identidade visual voltada à conscientização.

## 🌍 Importância do projeto

O racismo é um problema social que precisa ser combatido diariamente. Por meio deste projeto, buscamos reforçar que o respeito deve estar presente em todos os espaços.

**No esporte ou na sociedade, racismo não tem lugar.**
